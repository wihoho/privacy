SuggestScope privacy policy

Last updated October 31, 2026

This policy covers the SuggestScope – Free Amazon Keyword Research Tool for Sellers & KDP Chrome extension (“SuggestScope”). In short: SuggestScope does not collect, sell or share your personal data. It has no account, no ads and no tracking. It sends only the anonymous counts described below.

Information the extension handles

  • The keywords you type into Amazon's search box or the research page, which are used to request Amazon's search suggestions.

This information is used only to provide the extension's features on your device. It is never sent to the developer.

Anonymous usage counts

So we can tell whether SuggestScope works for people, it sends a small anonymous report to our server (extstats.share.zrok.io) when it is installed, when you finish its main task, and when an error happens. A report contains only the extension's public ID and version, the event, and for errors a shortened error message with file names, web addresses, numbers and quoted text removed. It never contains your files, recordings, page content, names, what you typed, or any identifier for you or your browser. The server keeps daily totals only and doesn't store IP addresses.

Storage

Your settings, last marketplace and starred keywords are stored in Chrome extension storage on your device. Uninstalling the extension removes its stored data.

Third parties

Keyword suggestion requests go directly from your browser to the Amazon marketplace you are using (the same requests Amazon's own search box makes), under Amazon's privacy policy. Nothing is sent to the developer.

What we don't do

  • We don't collect personal or sensitive information or browsing history. The only usage data are the anonymous counts above.
  • We don't sell or transfer user data to third parties.
  • We don't use or transfer user data for purposes unrelated to the extension's single purpose.
  • We don't use or transfer user data to determine creditworthiness or for lending purposes.

The use of information received from Google APIs and Chrome extension APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Children

The extension is not directed at children under 13 and does not knowingly collect information from them.

Changes

If this policy changes, the updated version will be posted on this page with a new date.
