drama-cut privacy policy

Last updated November 19, 2026

drama-cut is a private video editing tool that its developer runs on their own computer to publish commentary videos to YouTube channels they own. It is not offered to the public: the only Google accounts that sign in to it are the developer's own.

Google user data it uses

  • YouTube Data API (youtube.upload, youtube.force-ssl): to upload videos, captions and thumbnails to the signed-in channel, set a video's privacy and schedule, read a video's processing and copyright (Content ID) status, and delete the developer's own test uploads.
  • YouTube Analytics API (yt-analytics.readonly): to read view counts and watch time of the channel's own videos.

Storage

OAuth tokens and the data above are stored only on the developer's own computer, in files readable by the developer. They are never sent to any server other than Google's.

Sharing

No Google user data is sold, shared with or transferred to anyone. It is not used for advertising and not used to train AI models.

Deletion

Removing the tool's access in your Google Account (Security → Third-party apps) revokes it; deleting the tool's folder removes everything it stored.

Compliance

drama-cut's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube API Services Terms of Service; see Google's Privacy Policy.

Contact

Questions or requests: open an issue on GitHub.
