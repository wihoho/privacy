How to use voice typing on any website in Chrome

Quick answer: Install the free SpeakType extension and allow the microphone. Click into any text box, press Alt+Shift+D and start talking; say “comma”, “period” or “new line” for punctuation, and “stop listening” when you're done.

Google Docs has voice typing built in, but most other sites, like Gmail, web forms, chat apps and CMS editors, don't. Windows and macOS have system dictation, but it's not on every computer or Chromebook and it doesn't understand the page you're on.

Step by step

  1. Add SpeakType to Chrome

    Install SpeakType from the Chrome Web Store. It's free with no account.

  2. Allow the microphone

    On the welcome page that opens after installing, click Allow microphone. Chrome asks once.

  3. Click into a text box

    Any site: an email, a form, a chat message or an editor.

  4. Press Alt+Shift+D and talk

    Your words appear at the cursor. Say punctuation out loud, and “delete that” to undo the last phrase.

Tips

  • 47 languages are supported; spoken punctuation works in English, Spanish, French, German, Portuguese and Italian.
  • Everything you dictate is also kept in the side panel notepad, so nothing is lost.

Other ways to do it

Google Docs (Tools → Voice typing) is great for long documents. Windows (Win+H) and macOS (by default, press the Fn or Globe key twice) have system-wide dictation if your computer supports it.
