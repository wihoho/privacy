How to turn an email or flyer into a Google Calendar event

Quick answer: Install the free NanoEvent extension. Select the text with the date and time (or right-click an image of a flyer), choose the NanoEvent item, check the details it fills in, and click Add to Google Calendar.

Gmail only suggests events for some emails, like flight and restaurant bookings. For a school newsletter, a club email, a poster or a booking page, you usually end up copying the date, time and address into Calendar by hand.

Step by step

  1. Add NanoEvent to Chrome

    Install NanoEvent from the Chrome Web Store. It's free with no account.

  2. Select the event details

    Highlight the part of the email or page that mentions the event. For a poster or screenshot, right-click the image, or use the crop tool to select part of the page.

  3. Right-click and extract

    Choose “✨ Extract Event from Text (AI)” (or the image option). NanoEvent reads the title, date, time and place.

  4. Fix anything in plain words

    If something is off, type a correction like “move to Friday at 4 PM” and it updates the event.

  5. Add it

    Click Add to Google Calendar, or export to Outlook on the web or an .ics file for any other calendar.

Tips

  • A whole schedule in one email? NanoEvent finds several events at once; add the ones you want.
  • Try it first on the practice flyer: wihoho.github.io/privacy/extensions/nanoevent/try/

Other ways to do it

Gmail's own event chips work for some booking emails, and you can always create the event by hand. NanoEvent helps with everything else: newsletters, posters, web pages and screenshots.
