Questions

How is this different from Chrome's own site search?

OmniSearch adds sites from a right-click, understands shortened keywords and multi-site searches, and keeps a suggested list ready, all managed in the side panel.

Does it read the pages I visit?

No. It doesn't run on the pages you visit. It only reads a site's search box when you choose “Add a keyword for this search”, and only types into a site for advanced shortcuts you set up yourself.
