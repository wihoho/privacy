Questions

How do I add an event to Google Calendar from an email?

Select the email text, right-click and choose the NanoEvent item, check the details, then click Add to Google Calendar.

Can it read events from an image or screenshot?

Yes. Right-click an image, or use the crop tool to select part of the page.

Does NanoEvent send my data anywhere?

Only the text or image you select is sent to an AI service to read the event details. Nothing else on the page is collected.
